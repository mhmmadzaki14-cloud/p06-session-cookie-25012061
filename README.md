## Deskripsi

Aplikasi ini merupakan tugas praktikum Pemrograman Web I
Pertemuan 6 yang menerapkan penggunaan session dan cookie
pada aplikasi keranjang belanja sederhana.

## Fitur

- Menampilkan daftar produk
- Menambahkan produk ke keranjang
- Menambah jumlah produk yang sama
- Menampilkan jumlah item keranjang
- Menghitung subtotal
- Menghitung total belanja
- Menghapus item dari keranjang
- Mengosongkan keranjang
- Flash message
- Cookie untuk menyimpan preferensi tema
- Tema terang dan gelap
- Validasi input
- Escape output
